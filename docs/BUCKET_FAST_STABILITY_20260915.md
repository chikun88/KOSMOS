# 巡航速度を維持する固定バケツ周辺の修正

ゲート周辺を一律0.20 m/sにする前案を取りやめ、通常・sprintの巡航上限
**2.0 m/s**を維持した。直線ではゲート付近でも巡航できる。
これは設定上限であり、実機で2.0 m/sを測定したという意味ではない。

## 変更内容

### 通過した中継点へ戻らない判定

Nav2用の `RemovePassedBucketGoals` を追加した。
中央バケツを避ける2点 `(-1.55, 0.15)` / `(-1.55, -1.25)` と右側の対称点だけに、
元の半径0.16 mに加えて、次の通過条件を適用する。

- バケツの外側（左フィールドはxがゲート以下、右はゲート以上）にいる。
- 次の目標へ向かう方向に、ゲートのY座標を2 cm以上越えた。
- ゲートから0.45 m以内、レーンの向きから0.04 rad以内にいる。
- TFの自己位置が0.30秒以内で新しい。

内側を横切る動き、ゲート手前、異なる向き、古い自己位置では通過扱いにしない。
タグのない狭い進入・退出ゲートは元の0.16 m判定を使い、最終目標は削除しない。
毎BT周期で判定する。通過後の経路も通常どおりNav2が計画する。

### 曲がる区間だけ制御する

- 狭いレーン入口の急な曲がり方を検出したときだけ、0.20 m/sの曲がり速度へ
  事前に減速する。ゲートの手前0.25 mから、出口0.25 mまで余裕を取る。
- 中央通路の曲がる部分は0.40 m/sを基準に、前後の速度を応答遅れと加速度から
  計画する。直線にはこの制限を掛けない。
- 経路の再計画で曲がり角が経路先頭から消えても、通過中の制限を引き継ぐ。
- 基準速度だけを下げると、位置補正が速度を上乗せして減速を打ち消していた。
  必要な曲がり速度は**補正後の指令全体**にも適用する。
- 曲がり終えたら元のプロファイルで加速する。衝突監視、速度・車輪・加減速の
  制限、到着時の減速、緊急停止は維持する。

`config/routes.yaml` の `fixed_gate_tracking` は曲がる区間用の設定。
固定点の近くという理由だけで直進を低速にする設定ではない。

## 比較結果

[再生スクリプト](../scripts/check_bucket_gate_replay.py)で、記録された往復経路、
実測応答ゲイン、実際の追従制御・RuntimeGuard・UART飽和を使って比較した。
候補の通過判定にはビルド済みBTライブラリの同じ関数を使う。
再計画は記録経路を保持しつつ、車体全体のCAD検査を通る直結だけを許可する。

往復2方向×左右2フィールド×遅れ3条件の12条件で、全ゲートを通過して到達した。
遅れ/一次遅れは0.10/0.08秒、0.20/0.12秒、0.30/0.15秒。
最後の条件では応答ゲインも10%増やした。

|指標|一律0.20 m/sの前案|今回|
|---|---:|---:|
|到達時間|20.03〜22.07秒|15.15〜16.56秒|
|中央通路での速度中央値の比|1|1.79〜2.39倍|
|各条件の最大速度|—|0.867〜1.034 m/s|

同じ条件どうしの到達時間は**23〜27%短縮**した。
今回の後戻り距離の最大値は4.61 cm、サンプル時点の最小CAD余裕は15.13 mm。
高速化した条件では短い位置補正が残るため、後戻りゼロとはしていない。
結果と使用ファイルのハッシュは [再生結果](bucket_fast_replay_20260915.json)。

  最終目標の保持、再要求、TF欠落・期限切れ、座標系不一致を確認。
- 関連Python試験196件を確認。速度制御の新規10件は試験の測定条件を修正した後に
  再実行して成功。左右のCAD通過領域、再計画、既存の軌道生成も含む。
- `colcon build --symlink-install --packages-up-to omni_autonomy_next` 成功。
  新しいBTライブラリがない場合は `run.py` がビルドする。
- 全体試験で前回確認した既存3件の停止確認時間に関する不一致は、今回の変更対象外。
  詳細は[前回の検証](BUCKET_STABILITY_20260915.md)を参照。

## 適用と検証の限界

**システムの再起動後から適用。実機走行は未確認。**
実機システムが起動中だったため、CPU負荷を増やすNav2全体のデモは今回は起動していない。
再生は実際のSmac再探索、自己位置推定、TF・センサー通信、ライブ衝突監視を再現しない。
サンプル時点のCAD余裕は実機の接触回避を保証する値ではない。

```bash
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
python3 scripts/check_bucket_gate_replay.py
```
