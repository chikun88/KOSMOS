# 向きを保持する走行方式の高速化（2026-09-06）

対象: egg8PC `/home/egg8/Desktop/omni_autonomy_next`、bacon6 `/home/bacon6/omni_autonomy_next`。

## 変更

- 旋回の主区間では従来より強い角度応答を使い、制動角度を考慮して角速度を制限する。目標付近では低いゲインへ一度だけ切り替える。行き過ぎるたびに高速側へ再投入しないため、応答倍率や遅延による持続的な往復旋回を防ぐ。
- 旋回前後の停止確認を各0.30秒から0.10秒へ短縮。実測並進速度・角速度・角度・自己位置・旋回空間の確認は維持する。
- 旋回中に出発用の経路を準備する。目標の世代、速度プロファイル、出発位置が一致した経路を引き継ぎ、旋回完了後の計算待ちを除く。キャンセルで準備済み経路も捨てる。
- 通路の横の壁までの距離による並進速度制限を除き、車輪・速度プロファイル・曲率・加減速の制限を使う。実際の指令方向と実測速度それぞれの遅延込み制動軌跡を車体全体で確認する。
- 車体と壁の厳密な距離判定を最大24姿勢ずつまとめて計算する。輪郭の交差、壁線分を車体が内包する場合、不正な自己位置も従来同様に拒否する。制動軌跡ではサンプル間の車体移動分も余裕から差し引く。
- 経路更新と制御周期の競合を修正する。旧経路を計算している間に経路が更新・キャンセルされたとき、古い指令や時刻を新しい経路へ書き戻さない。
- 制御タイマが処理負荷で遅れた場合も実際の経過時間で軌道と加減速を進める。1周期あたりの追いつき量を制限し、停止中も時刻を更新して復帰時の飛び出しを防ぐ。
- 旋回地点への同じ接近経路で加速の時刻をリセットしない。最後の1 cm程度の経路が2点だけとなり、両端速度ゼロのまま極端に長い時間割になる問題も修正する。
- 再計画が選択済み旋回地点を10 cm以上外れても、一律停止せず、その地点への前後の接続経路を車体全体で検査して維持する。壁を横切る接続は拒否する。

## 実機への適用と速度の限界

両ホストへ対象ソース・テスト・本書だけをチェックサム確認、バックアップのうえ反映する。モータ・計測輪・LiDARの校正、ハード上限、通信設定は変更しない。既存GUIの「広い場所で旋回 → 向きを保持して移動」を使い、次回システム起動から有効になる。

現設定の車輪上限15.709 rad/s、半径0.05 mから、純粋な車体軸方向の並進上限は約1.11 m/s、斜め45度は約0.785 m/s。balancedの上限は前後0.78 m/s、左右0.702 m/sで、区画・安全ゲートがさらに制限する。競技ロボットと同等の絶対速度を実現したという検証ではない。この上限を超える実機運転には、モータ指令と実速度、積載時の制動・滑り、自己位置追従の実測に基づく再校正が必要。
