# 計測輪オドメトリの原点リセット

`/wheel/reset_odometry` は調整作業用のサービスです。稼働中に `odom` の原点を
変更すると、自己位置推定や経路追従が原点の変更を実際の移動として扱うため、
次の条件を満たす場合だけリセットを受け付けます。

- オドメトリ配信トピックと標準 `/odom` に購読者がいない。
- 最新の計測輪速度が有効期限内で、並進速度が 0.01 m/s 以下、角速度が
  0.02 rad/s 以下である。

ロボットを停止し、自己位置推定・ナビゲーション・経路追従などの購読ノードを
停止してから実行してください。リセット後は購読ノードを再起動し、必要に応じて
地図上の初期位置を設定します。USB 読み取りエラーや時計の巻き戻り直後は、
新しい正常な計測が得られるまでリセットを拒否します。

リポジトリ内の既存コードには、このサービスの呼び出し元はありません。
