# 回転しながら3 m/sへ向けた予測制御

**制御を実装し、校正済みハードウェアのsimultaneous・sprintで有効にした。
実機の3 m/s走行と、実フィールド全地点での3 m/sは未確認。**
稼働ノードの再起動・走行指令送信は行っていない。次回起動後のsprintで使用する。
起動時のプロファイルは引き続きbalanced。

## 制御の変更

従来は現在の計測速度を0.32秒先へ直線的に外挿していた。
新しい処理は送信した機体座標系の指令履歴、0.30秒の遅れ、0.15秒の一次応答から
将来の位置・姿勢・速度を積分する。予測時間定数は今回のモデル検証に用いた設計値で、
実機で新たに同定した値ではない。
前周期の並進指令を予測姿勢の座標系へ変換してから加速度制限を行う。
これにより、車体が回転したために必要になる指令方向の変化を、
実際の進路変更と同じ減速度予算で抑えていた遅れを減らす。

CADで経路全体の余裕を確認できるsprint経路の回転中予算を1.30→3.00 m/sへ変更した。
開放経路では従来の4 m/s要求を維持し、車輪と回転が共有する出力を使う。
3 m/sは常時の実速度を保証する値ではない。
機体軸方向へ発進する開放経路では姿勢変更を三次曲線で滑らかにし、
加速開始時に大きく姿勢を変えて車輪予算を消費することを抑えた。
斜め方向の発進は途中の姿勢整列を生かすため従来の配分を使う。
変更前後の姿勢列の両方で35 cmの経路余裕条件を確認する。

中間予算の資格条件は、経路全体のCAD余裕からサンプル間の並進・回転の
外周移動上界を引いても25 mm以上あること。同じ目標の再計画では
従来どおり資格の取り消しだけを認め、途中からの昇格をしない。
条件を満たさない経路は既存の予算と追従制御を継続する。
車輪上限、UART上限10000、曲率、停止距離、ライブ衝突監視も継続する。
25 mmは実機安全性を認証する余裕ではない。

`robot.yaml`の`calibrated_tracking.predictive_sprint: true`で有効。
送信補正0.38／0.34が一致するハードウェアのsimultaneousモードに限定し、
balanced・precision・分離旋回には適用しない。
`false`へ戻して再起動すると、この変更以前の1.30 m/s制御へ戻る。

`/trajectory_tracker/status`のTRACKINGに以下を追加した：

- `predictive_sprint_active`：予測制御の使用状態。
- `measured_linear_m_s`、`measured_angular_rad_s`：同時刻の計測フィードバック。
- 既存の`local_linear_limit_m_s`：今回の中間予算では3.0。

予測にはtrackerの発行指令を使用する。下流の衝突監視等による削減を完全に予測する
モデルではないため、その影響や実負荷を含む実走検証は別途必要。

## 実記録25経路の再生

[ソースハッシュ付き比較結果](predictive_sprint_routes_20260916.json)。
遅れ0.20秒／一次応答0.12秒と、遅れ0.30秒／一次応答0.15秒の計50条件。
変更前に到着かつCAD余裕15 mm以上だった19条件について、
新たな余裕不足・未到着・0.15秒超の到着遅延は0条件。
変更前から基準未達の31条件を合格扱いしていない。

7経路・14条件で動作が変わり、13条件で到着が5.8〜28.2%短縮した。
残る1条件は8.52→8.53秒で0.01秒遅く、他の18経路・36条件は同じ結果だった。
変更が効いた経路のモデル最高速度は1.151〜1.848 m/s。
**この実記録の経路で3 m/sに達したという結果ではない。**

例：経路89760・遅れ0.30秒では、到着13.76→10.37秒、最高速度0.991→1.594 m/s。
最小CAD余裕は84→39 mmで、余裕は減るが比較基準を満たした。
経路22108・遅れ0.30秒は、到着9.72→8.99秒、CAD余裕0→112 mm。
全地点への無条件適用を示すものではない。

## 開放経路での同時3 m/s判定

[ソースハッシュ付き結果](three_mps_turning_open_20260916.json)。
障害物のない仮想30 m経路で、姿勢を±90度変更する試験。
機体のモデル真値について、並進3 m/s以上と角速度の絶対値0.05 rad/s以上が
同時に1秒以上連続すること、到着・停止すること、最大横ずれ35 cm以下、
UART各輪10000以下を判定する。単なる速度ピークでは合格にしない。
8方向×遅れ2条件の16条件すべてで、この同時走行判定を満たした。
3 m/s以上で回転した連続時間は1.48〜3.34秒、連続移動距離は4.74〜10.99 m。
回転中のモデル最高速度は3.330〜3.620 m/sだった。
実フィールドの通路長・障害物配置を再現した試験ではない。

このモデルは低速で測った応答ゲインを高速へ外挿している。
荷重・滑り、自己位置異常、ライブ衝突監視は再現しない。
モデル真値の3 m/sを実機達成と表現しない。

## 再現

```bash
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
OPENBLAS_NUM_THREADS=1 python3 scripts/check_predictive_sprint.py \
  --output /tmp/predictive_sprint_routes.json
OPENBLAS_NUM_THREADS=1 python3 scripts/check_three_mps_turning.py \
  --output /tmp/three_mps_turning_open.json
```

モデル予測・回転座標・同時速度の連続時間・校正条件・各モードを含む関連テストは
初回の広域確認は395件成功、分離旋回の停止待機に関する既存テスト2件が失敗。
その後、古い指令履歴・未来時刻の指令履歴を予測に使わない処理を追加し、
新規テスト2件を含む関連68件を再実行して成功した。50条件・16条件の再生も最終コードで再実行した。
今回変更していない`staged_heading_node.py`の50 ms停止確認に対し、
`test_staged_continuity.py`の2件はより長いSETTLEを期待している。
テスト期待値や分離旋回の待機時間は変更していない。
colcon buildは4パッケージ成功。
