# 保存地点Aの低速直線後退

- 対象は保存名が厳密に `A` の呼び出し。ほかの保存地点・番号指定は従来通り。
- 保存姿勢の前方0.25 mをNav2の一次目標にし、計測速度・位置・向きの到達確認後に後退へ移行。
- 後退は最大0.05 m/s、横速度0。目標向きを小さな角速度で維持し、終点で減速する。
- 保存Aを更新すると、次の呼び出し時に新しい位置・向きから開始地点を再計算。
- 横ずれ2 cm超、向きずれ0.04 rad超、後退区間逸脱は停止。自己位置・速度・指令元の監視、20秒制限、キャンセル・目標切替を維持。
- 全後退区間のCAD機体形状と制動軌跡を確認。保存Aの最小CAD余裕は約28.3 mm。後退専用で25 mmとサンプル間の余裕を確保し、横方向への回避補正は行わない。下流のCollision Monitor・RuntimeGuardも従来通り適用。
