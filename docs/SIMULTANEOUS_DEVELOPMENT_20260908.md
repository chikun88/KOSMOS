# 回転しながら移動する制御の開発方針

実験で実用性を確認できたという利用者の報告を踏まえ、今後の主方式を
`simultaneous`（回転しながら移動）とする。既存の起動時既定値もこの方式。
精度、移動時間、滑らかさを同じ経路・同じ速度倍率で比較して改善する。

## 今回の変更

旋回と並進に必要な加速度を区間ごとに計算し直し、従来の固定的な50:50の
割当によって生じる余分な減速を減らす。経路上の位置・向きの列を維持し、
各車輪速度、並進速度、角速度、加速度、最終段のジャーク制限を使う。

弧長をs、姿勢の弧長微分をq、並進速度の二乗をuとすると、角加速度は
`q' u + q a`。区間内の必要量を
`|q'| max(u0,u1) + max(|q0|,|q1|) |u1-u0| / (2 ds)`
で上から抑え、上限以内の到達可能速度を前向き・後ろ向きに解析計算する。
どちらかの項が使わなかった余裕をもう一方に使える。

短距離で大きく向きを変える、旋回の加速度が支配的な場合は従来の配分を維持する。
判定は `max(|q|) × 並進加速度上限 > 角加速度上限`。
全区間で余裕を使い切る候補は、駆動倍率2.8・遅れ0.30秒の短距離試験で
姿勢の整定が悪化したため採用しない。停止期限や到達精度を緩めて通過させない。

## 開発・評価の基準

- 主方式は同時旋回。停止旋回方式は比較・既存用途として維持する。
- 高速化は最高速度の設定値だけで判断せず、指示から位置・姿勢・速度が
  整定するまでの時間で評価する。
- 精度は位置誤差と角度誤差、滑らかさは指令の加速度変動とジャークで確認する。
- 保存Aの低速後退、保存地点の無線指示、目標切替、障害物・自己位置・通信異常への
  停止処理について回帰試験を維持する。
- 実走行では `python3 run.py record-run` で最終指令と計測速度を時刻付きで記録する。
  同じ経路・同じ倍率を複数回比較し、駆動較正と遅れを確認してから速度上限を検討する。

今回の比較はソフトウェアとモーター出力なしの疑似走行による検証。
利用者が確認した実用性と、今回の改修による実機上の速度向上は別の検証事項。
実測前に「超高速化を達成」とは判定しない。
