# 走行途中で極低速になる問題の修正

## 原因と根拠

実機記録 `20260914T220637.760213Z-9351c814`（日本時間2026-09-15 07:06開始）で、
追従指令が約0.95 m/sある間も衝突監視後は約0.01 m/sとなり、低速状態が続いていた。
この間、速度倍率は1.0、追従器はTRACKINGだった。直後の07:15開始記録は
DISARMED / IDLEで、走行の根拠には使っていない。

後方LiDARのレーザー座標で約23.86〜29.19度・0.274〜0.289 mの反射が、
移動・旋回後も機体座標のおよそ x=-0.492〜-0.469、y=0.095〜0.113 mに残る。
これは従来のCADフットプリントからのレーザー方向50 mm除外の外側だった。
操作者から「減速中、障害物はなかった」と回答を受け、機体に固定された自己反射と
判断した。どの配線・部品が反射元かは現物を調査していない。

Nav2 1.3.12の[衝突時刻計算](https://github.com/ros-navigation/navigation2/blob/1.3.12/nav2_collision_monitor/src/polygon.cpp)と
[速度縮小処理](https://github.com/ros-navigation/navigation2/blob/1.3.12/nav2_collision_monitor/src/collision_monitor_node.cpp)を確認。
この点へ向かう後退・旋回では直後に衝突すると予測され、並進と旋回が一緒に
0〜約8%へ絞られる。機体に追従する反射なので、少し移動しても減速条件が消えない。

## 修正

`robot.yaml` の後方LiDARだけに、センサー座標の23〜30度 **かつ** 距離0.270〜0.292 m
の自己反射除外を追加した。角度だけの除外や機体全周のマージン拡大は行わない。
`scan_footprint_filter_node.py` がトピックとフレームを照合し、該当点だけをNaNにする。
NaNは障害物マーキングにも空き領域クリアにも使わない。前方LiDARと範囲外の
近い／遠い反射は保持する。除外は設定に明記し、実行中に自動学習・拡大しない。

既存の衝突予測時間・SlowZone・非常停止・鮮度監視・速度上限は保持した。
生LiDARの記録にも手を加えない。センサーや配線を移した場合はこの狭い除外範囲を
再確認する。同じ角度・距離の窓に入る実物も除外対象となるため、この設定は今回の
実測と操作者確認に基づく機体固有の補正であり、汎用的なノイズ除去ではない。

## 再生検証

[入力スキャンと元ファイルのSHA-256](slowdown_scan_fixture_20260915.json)には、
160・175・200秒付近の前後フィルタ済みスキャンと要求指令を、元の記録番号・発行時刻・
計測時刻付きで保存した。各窓の選択は受信時刻に最も近いサンプルであり、
記録された全通信やTFを時刻どおりに再現した試験ではない。

`scripts/check_slowdown_replay.py` はインストール済みNav2のネイティブなPolygon実装へ
同じ点群を入れる。ROSノード・速度配信・モーター通信は作成しない。
取り付け姿勢とCAD形状を照合し、元のSlowZoneも含めて出力を比較する。

| 記録の窓 | 修正前の並進出力 | 修正後の並進出力 |
|---|---:|---:|
| 160秒付近 | 0.000 m/s | 0.750 m/s |
| 175秒付近 | 0.037 m/s | 0.710 m/s |
| 200秒付近 | 0.031 m/s | 0.293 m/s |

これは**同じ瞬間の点群・指令に対する再計算値**であり、変更後の実走速度ではない。
各窓で除いたのは後方の7〜10点だけ。前方およびその他の反射点は残した。
同じ後方26度に距離0.32 m／0.50 mの障害物を追加した試験は、それぞれ約4.2%／12.5%
への減速を維持。機体内の障害物ではゼロ、障害物なしでは通常指令となった。
[数値結果](slowdown_replay_20260915.json)と `logs/slowdown/replay.log` を参照。

再現コマンド:

```bash
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
python3 scripts/check_slowdown_replay.py --output /tmp/slowdown-replay.json
```

変更は次回の通常起動で読み込まれる。実機の自動再起動や走行指令は行っておらず、
変更後の実走確認は未実施。

## ソフトウェア検証結果

- 追加の自己反射テスト11件成功。角度・距離の境界、逆順スキャン、誤フレーム、
  前方センサー、NaN出力、範囲外の障害物保持、不正設定、記録スキャンを検証。
- ROSドメインを184へ隔離した全体テストは695件成功・3件失敗。
  失敗は `test_planned_stop.py::test_transport_drains_after_last_braking_command` と
  `test_staged_continuity.py` の `test_passing_gate_by_two_centimetres_does_not_command_a_return`、
  `test_stop_confirmation_resets_after_measured_motion`。
  今回の自己反射変更だけを除いた作業ツリーの一時コピーでも3件すべて同じ失敗を確認。
  既存の段階旋回の待ち時間に関する別件で、この修正では変更していない。
  `logs/slowdown/tests.log` と `logs/slowdown/baseline-failures.log` を参照。
- `colcon build --symlink-install --packages-up-to omni_autonomy_next` は3パッケージ成功。
  `logs/slowdown/build.log` を参照。
