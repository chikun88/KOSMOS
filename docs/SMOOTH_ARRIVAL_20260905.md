# 2026-09-05 滑らかな回転移動・短距離到達の修正

egg8PC の実運用追従器を修正し、bacon6 には共通の軌道数値計算を移植した。
既存の未コミット変更を保存し、モーター出力を有効にせず検証した。
実機での到達精度・振動の解消・全地点への走行保証を示す結果ではない。

## 今回修正した原因

1. **その場での向き変更が無視される。** 1点経路を受信時に捨て、同じ位置の
   複数点経路も再サンプリング後に捨てていた。1点は位置を保持する終端目標として
   扱い、既存の角度制御・角加速度制限・衝突監視を通して旋回する。
   回転のために並進経路を作り足さない。
2. **短距離の旋回計画が角加速度制限を超える。** `q=d(yaw)/ds` とすると角加速度は
   `q'(s)*v² + q(s)*a`。後者が計画から漏れていた。各区間の速度と加減速度に
   両項の予算を割り当てる。点の間にも角速度のピークが生じるため、点間の上限も
   保証する。検証範囲は距離 0.02/0.04/0.1/0.3/1/3 m、角度 +90/-180/+11.46度。
   18条件すべてで参照角速度 ≤1.3 rad/s、参照角加速度 ≤2.0 rad/s²。
   フィードバックを加えた指令には、引き続き出力側の加速度制限が働く。
3. **終点付近で並進指令が段差になる。** 残り10 cmで突然位置サーボへ切り替えていた。
   20～10 cmの間を3次の補間で連続的に切り替え、10 cm以内では従来の低速位置合わせを使う。
4. **短距離の大きな回転や一時停止が時間切れになる。** 速度倍率0ではゼロ指令を出し、
   終端の待ち時間をリセットする。目標位置付近で角度誤差の最良値が0.02 rad以上
   改善した場合は整定の進捗として数える。同じ経路の再計画や同じ目標の再通知だけでは
   延長しないため、動かない旋回はタイムアウトする。同じ位置で新しい向きを指定した場合は
   新しい目標として待ち時間をリセットする。

## 単純な方式との比較

単純な最短角度の補間と、動的計画法による姿勢最適化を再比較した。
単純補間の `optimize_yaw=false` を維持した。最適化には旋回の滑らかさで有利なケースもあるが、
今回の4区間では総合的に置き換える根拠がない。

120 msの無駄時間・80 msの一次遅れ・20 Hzの制御モデルによる結果:

| 区間 | 修正前・単純補間 | 修正後・単純補間 | 修正後・姿勢最適化 |
|---|---:|---:|---:|
| 1→4、90度変更 | 5.78秒 | 5.78秒 | 5.95秒 |
| 1→2、90度変更 | 4.44秒 | 4.50秒 | 4.73秒 |
| 4→5、向き維持 | 5.84秒 | 5.84秒 | 5.84秒 |
| 3→6、約11度変更 | 4.85秒 | 4.85秒 | 4.84秒 |

1→2の単純補間では、始動直後を除く要求角加速度ピークが3.312→2.642 rad/s²
（約20%減）。到達時間は0.06秒増える。横方向追従誤差の最大値は約12.65 mmで同等。
この比較は障害物・固定進入レーンを含まない自由空間の制御則比較であり、
実フィールドの1→2走行時間や安全余裕としては使えない。
