# 自動制御の停止・旋回安定性修正（2026-09-12）

対象はこの比較版のローカルワークスペース。既存の未コミット変更を保持して修正した。
実機走行、モーター起動、リモート機への配布は実施していない。

## 修正内容

- 段階旋回モードの進入→停止確認では、停止領域の安全を確認してから既存の
  加速度制限で減速する。従来は 0.07 m/s の指令を1周期でゼロにしていた。
  既定の50 ms周期・0.85 m/s²では 0.07→0.0275→0 m/s になる。
  旋回開始には指令のゼロ、実測速度の低下、最後の移動指令からの伝送待ちを必要とする。
  障害物・位置逸脱・キャンセル・各安全ゲートによる停止は即時のまま。
- 通常モードの固定姿勢移動（姿勢最適化なし、現在と目標の向きが一致）でも、
  平滑化による角の切り込みを既存のCAD経路補正で修正する。
  始点・終点は動かさず、補正後は区間途中と姿勢誤差の余裕を含めて検証する。
  補正できない経路は走行せず再計画を待つ。障害物監視の閾値は緩和しない。
- 通常モードの180度旋回では ±π 付近の微小な自己位置ノイズで旋回方向を
  往復させない。0.05 radの範囲に方向保持を設け、新しい目標では履歴をリセットする。
- 並進距離ゼロのその場旋回には経路に沿う減速計画がないため、角速度を
  最大0.6 rad/sに制限する。遅延300 ms・一次遅れ150 ms・応答倍率2.8の
  回帰モデルでも整定を確認する。
- 自己位置の鮮度を受信時刻ではなく計測時刻で評価する。
  古い・未来・非数値・順序逆転のデータで制御位置や鮮度を更新しない。
