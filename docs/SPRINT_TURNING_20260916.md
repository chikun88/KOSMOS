# 回転しながらのsprint移動

## 実装した動作

sprintで、**残り経路全体に十分なCAD余裕がある場合**、回転中にも並進4 m/s要求の
プロファイル予算を使う。従来は姿勢が変わる区間に1.05 m/s・車輪15.709 rad/sの
固定上限があり、開けた長い経路でも約1 m/sだった。

新しい処理は既存の方向・姿勢・角速度を含む車輪予算を使用する。並進4 m/sと
最大旋回速度を同時に保証するものではなく、各輪出力を共有して速度を計画する。
UART上限10000、角加速度、曲率、制動、終端停止、ライブ衝突監視は引き続き適用する。

高速予算を使う条件は、車体ポリゴンのCAD余裕からサンプル間の並進距離と
回転外周移動の上界を引いても、残り経路の全点で0.35 m以上あること。
CAD／車体形状がない場合や非有限値を含む場合、狭い経路、balanced／precisionでは
従来の回転中予算を維持する。0.35 mは後述のモデル最大横ずれ0.228 mを超える
追従余裕として設定したもので、実機の高速安全性を認証する値ではない。

`/trajectory_tracker/status` に実際に適用する `local_linear_limit_m_s` と
`local_wheel_budget_rad_s` を追加した。全体のsprint設定と、その地点で実際に
適用される制限を次の実走ログで区別できる。

## 仮想的な開放経路での結果

[比較JSON](open_sprint_turning_replay_20260916.json)と
[再現スクリプト](../scripts/check_open_sprint_turning.py)。
空いた30 mの直線移動に±90度の姿勢変更を重ね、4方向×応答遅れ2条件で比較した。
最新実機ログの低速応答ゲインを外挿し、実装のtracker・guard・UART飽和を通した。

|8条件の範囲|従来の回転中固定上限|今回の開放経路予算|
|---|---:|---:|
|モデル最高速度|1.025〜1.075 m/s|3.108〜3.563 m/s|
|回転中のフィルタ済み速度フィードバック最大|1.026〜1.090 m/s|3.107〜3.560 m/s|
|モデル到着時間|37.28〜37.84秒|14.34〜14.97秒|
|最大横ずれ|0.012〜0.029 m|0.069〜0.228 m|
|UART各輪指令の最大|3044〜3057|10000|

回転中の集計はフィルタ済み角速度の絶対値0.05 rad/s以上で行った。
8条件ともモデル上で到着・停止した。**実速度4 m/sは未達成・未検証。**
高速域の実負荷応答、滑り、センサ誤差やライブ衝突監視はこの再生では再現しない。

## 最新の実経路では高速化していない

[最新9経路×遅れ2条件](sprint_turning_replay_20260916.json)を比較した。
今回の経路は狭い場所を含み、新しい余裕条件を満たさないため、18条件すべてで
速度・到着時間・CAD余裕は従来と同じだった。今回の実走経路が速くなったとは言えない。
6条件は従来からCAD余裕15 mm以上で到着、残る12条件は従来から余裕条件を満たさない。
この既存の問題を隠して全経路合格とは扱わない。

回転中の上限を無条件で外す案と、各地点の余裕だけで高速予算へ切り替える案は
追従／壁余裕が悪化したため採用しなかった。
[地点ごとの切替案の棄却結果](sprint_turning_local_clearance_rejected_20260916.json)。
経路再生ハーネスにも実CADモデルを読み込ませ、高速許可条件を実ローダー経由で評価した。

## 反映と検証

- 関連Pythonテスト253件成功。最終の余裕拡大後、新規回転走行テスト21件を再実行して成功。
- colcon buildは4パッケージ成功。インストール環境から最終の35 cm条件を読み込めることも確認した。
- ノード再起動後、sprint選択時に条件を満たす経路で適用する。
- 稼働ノードの再起動、実機への走行指令、高速実走試験は行っていない。

```bash
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
OPENBLAS_NUM_THREADS=1 python3 scripts/check_sprint_turning.py
OPENBLAS_NUM_THREADS=1 python3 scripts/check_open_sprint_turning.py
```

現在の実経路でも高速化するには、曲がり・姿勢変更・終端寄せを含めた経路の再設計と、
駆動出力・実負荷停止距離の測定が引き続き必要。
