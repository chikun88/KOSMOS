# 向き保持方式の戻り動作・切り替え改善（2026-09-06）

対象は egg8PC `/home/egg8/Desktop/omni_autonomy_next` と bacon6 `/home/bacon6/omni_autonomy_next`。
GUI の「広い場所で旋回 → 向きを保持して移動」で次回起動時から使う。

## 修正内容

- 経路の切り詰めを、最近傍の離散点から線分上の射影へ変更。現在位置より後ろの点を残して短い逆走区間を作る問題を修正。同時旋回モードと共通の処理にまとめた。
- 旋回地点の周囲3 cm以内に、現在位置と遅延込み停止距離が収まる場合は停止へ移行する。指令・実測速度、現位置での旋回空間とライブ地図も確認する。地点を少し通過した後に数学上の一点へ戻す補正を避ける。旋回開始時の実測停止位置を出発経路の起点にする。
- 停止・角度整定の継続確認を100 msから50 msへ短縮し、条件が成立した制御周期で次の動作を出力する。停止指令が通信経路を抜けるまでの必要時間は別途確保する。速度・角度・自己位置・障害物の閾値は緩めていない。
- 準備済みの出発経路へ切り替えた周期に、古い接近経路の指令を計算しない。目標世代・プロファイル・位置の一致検証を維持する。
- 出発経路を引き継ぐ際に、旋回地点への到達記録も出発先に合わせて更新する。旋回地点の残り距離を出発後に比較し続け、正常な走行を進捗なしと判定し得る問題を修正。

## 適用
