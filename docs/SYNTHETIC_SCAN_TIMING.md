# シミュレーションの LaserScan 時刻

合成スキャンは、各 LiDAR の計算直前に取得した機体姿勢を一度だけ評価する
瞬時スナップショットです。`header.stamp` はその姿勢に対応する時刻、
`time_increment` は `0`、`scan_time` はスキャンの配信周期です。

移動モデルを有効にした場合は、直近に配信済みのオドメトリ／TF と同一の
姿勢・時刻を一組で取得します。最初のオドメトリ配信前はスキャンを出しません。
前方 LiDAR の計算中にモデルが進んだ場合、後方 LiDAR は新しい配信済み状態を
取得します。計算後に古い点群の時刻だけを更新することはありません。
計算自体が遅延したスキャンは、通常の鮮度検証で棄却されます。

ROS の制御コールバックは単一スレッドで実行し、点群計算は専用の一つの
ワーカーで実行します。計算が配信周期を超えた場合、未処理の要求は一つに
まとめ、次の計算では最新の配信済み状態を取得します。古い取得要求を
キューに積みません。ワーカーの例外は制御側に伝播し、終了時は計算が
終わるまで待ってから ROS の配信オブジェクトを破棄します。

実機でも ROS の `scan_time` は「スキャン間の時間」であり、全ビームの取得に
要した時間ではありません。自己位置推定は `time_increment > 0` の場合だけ
各ビームの取得時刻を補間します。`time_increment == 0` のドライバーでは全点を
ヘッダー時刻として扱います。以前の `scan_time` を用いた補間は撤廃しました。
