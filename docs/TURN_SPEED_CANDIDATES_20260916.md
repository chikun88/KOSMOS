# 回転移動4 m/sに向けた追加比較

**全地点での高速回転移動・実速度4 m/sは未達成。今回の候補は適用していない。**
実機制御・設定を変更せず、回転中の中間予算を上げる候補と先読み補償の候補を
実記録の経路で比較した。走行指令の送信や稼働ノードの再起動は行っていない。

## 比較条件

保存済みの3組の実記録、計25経路について、遅れ0.20秒／一次応答0.12秒と
遅れ0.30秒／一次応答0.15秒を比較した。基本候補は回転中1.30 m/sの予算だけを
変更し、元のCAD資格条件、車輪合成上限、UART上限10000、制動を維持した。
補償候補では追加で制御tickの先読みを0.32秒から0.42秒へ変更した。
これらは無条件の4 m/s解除案ではない。

従来から到着かつ最小CAD余裕15 mm以上だった条件に対し、新たな余裕不足、
未到着、または0.15秒超の到着遅延を退行とする、既存比較スクリプトと同じ基準を使用した。
基準未達の条件を合格扱いしない。

|回転中予算|先読み|比較条件数|基準を満たす変更前条件|退行|新たなCAD余裕不足|
|---|---|---:|---:|---:|---:|
|1.60 m/s|現行|50|19|7|7|
|1.40 m/s|現行|50|19|3|0|
|1.35 m/s|現行|14|13|3|0|
|1.32 m/s|現行|14|13|1|0|
|1.60 m/s|0.42秒|14|13|5|4|

14条件の比較は、最初の探索で変化した7経路の両遅延条件に限定したもの。
条件数が異なるため、退行率だけで候補の優劣を比較しない。
全50条件中31条件は変更前から基準未達であり、全経路での安全性を示す結果ではない。

[探索結果](turn_budget_candidate_search_20260916.json)には全142条件の結果を保存した。
探索は一時スクリプトで実施し、開始時のソースハッシュは取得していない。
探索の再現用に[比較スクリプト](../scripts/check_turn_budget_candidates.py)を追加した。
1.60 m/sの7経路14条件はこのスクリプトで再実行し、開始・終了時のソースハッシュが
一致することを検証した。[再実行結果](turn_budget_verified_rejection_20260916.json)でも
退行7条件を再現した。終了コード1は候補の退行検出を意味する。

具体例：経路14214・遅れ0.20秒では、1.60 m/s予算により最高速度が
1.126→1.355 m/s、到着が9.34→8.81秒に改善する。一方、同じ経路の遅れ0.30秒では
モデルCAD余裕が92 mm→0 mmになった。速度だけ上げて採用できる結果ではない。
1.32 m/sまで増分を小さくしても、経路89760・遅れ0.30秒で到着が13.76→14.98秒となった。

## 4 m/sと全地点という目標に残る制約

- 純軸4 m/s要求だけでも、送信補正後の各輪要求は
  `4 × 0.38 × 7202 = 10947.04`となり、UART上限10000を超える。
  回転を重ねると同じ車輪出力をさらに共有する。これは要求指令の計算であり、実速度の実測ではない。
- 現行の制動モデルは減速度`0.75 × 0.85 = 0.6375 m/s²`、
  先読みと速度フィルタの合計`0.32 + 0.06 = 0.38秒`を使用する。
  4 m/sからの停止距離はモデル上約14.07 m。
  加速度3 m/s²で静止から4 m/sへ達する2.67 mを加えると約16.74 mとなり、
  短い区間での加速・停止と両立しない。これは実負荷で測定した停止距離ではない。
- 狭い通路では姿勢と車体外周が通過余裕を決める。回転の許可だけでなく、
  回転しながら通過できる経路形状と、遅れがある状態での追従を改善する必要がある。

低速応答ゲインの高速域への外挿、仮定した応答遅れを使ったオフラインモデルであり、
ライブ衝突監視、自己位置異常、荷重・滑りは再現していない。
CAD余裕ゼロはモデル上の接触・交差で、実機衝突を観測したという意味ではない。

## 検証・再現

既存の回転走行・sprint関連Pythonテスト98件成功。追加スクリプトの構文確認成功。
動作変更を配備していないため、今回の再ビルドや実機試験は実施していない。

```bash
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
OPENBLAS_NUM_THREADS=1 python3 scripts/check_turn_budget_candidates.py \
  --turn-speed 1.6 --cases 14214 22108 17958 26054 89760 31078 84808 \
  --output /tmp/turn_budget_replay.json
```

全25経路を比較する場合は`--cases`を省略する。
`--turn-speed 1.4`などで予算を指定し、補償候補は`--feedback-lookahead 0.42`を追加する。
このスクリプトは本番関数をメモリ内だけで差し替え、実機用コードへ書き戻さない。
